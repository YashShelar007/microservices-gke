# Contributing

This repo is archived and not taking new features. Fixes to the docs or manifests are welcome.

1. Run a service locally: `cd user-service && pip install -r requirements.txt && python app.py`, then `curl localhost:8080/users`. The order service works the same way on `/orders`.
2. There is no test suite.
3. Branch from `main`, keep the change small, and open a pull request that says what you ran.
